INTERACTION FLOW
================

1. User sees trigger tile/button
   ↓
2. User hovers → Tile highlights
   ↓
3. User clicks → Modal opens with fade-in
   ↓
4. User hovers over option → Option highlights
   ↓
5. User clicks option → Modal closes, navigation happens
   ↓
6. User lands on target page

Alternative:
3. User clicks X or outside → Modal closes with fade-out
